# teaching-skills

[Teaching skills](./SKILL.md)

## English

### What it does

Designs courses, syllabi, lessons, labs, exams, rubrics, slides, TA plans, accreditation mappings and bilingual materials.

### Example prompts

- Draft a 14-week syllabus for Empirical Software Engineering with labs and rubrics.
- Build a bilingual midterm exam and marking rubric for this AI ethics course.
