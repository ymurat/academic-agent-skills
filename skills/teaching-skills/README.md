Designs a course or syllabus, or builds lessons, labs, exams, rubrics, feedback, slides, TA plans, accreditation mappings or bilingual materials.

### When to use

Load this skill when the task matches: the user designs a course or syllabus, or builds lessons, labs, exams, rubrics, student feedback, slides, TA plans, accreditation mappings, or bilingual course materials.
