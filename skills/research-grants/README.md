# research-grants

[Research grants](./SKILL.md)

## English

### What it does

Writes or reviews a grant or research proposal (aims, objectives, review criteria, budget, impact, resubmission, data management plan).

### When to use

Load this skill when the task matches: the user is writing or reviewing a grant or research proposal (aims, objectives, review criteria, budget, impact, resubmission, data management plan).

### Example prompts

- Structure aims, objectives and a data management plan for this ARDEB-style proposal draft.
- Review this resubmission against the panel comments. Do not invent budget figures.

### Inputs and outputs

**Inputs**

- User task and relevant documents
- Constraints stated by the user

**Outputs**

- Structured output defined in SKILL.md
- Limitations and unverifiable items marked plainly
