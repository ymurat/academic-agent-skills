## English

### What it does

Drafts, revises or audits a paper section (abstract, introduction, related work, methods, results, declarations) or a submission package.

### When to use

Load this skill when the task matches: the user drafts, revises or audits a paper or paper section (abstract, introduction, related work, methods, results, declarations) or a submission package.

### Example prompts

- Draft the Related Work section from these notes. Mark every claim that still needs a citation.
- Audit the abstract and contributions list for overclaiming before submission.
