# TÜBİTAK ARDEB proposal

Upstream: `resources/alterlab/skills/turkish-academia/alterlab-tubitak-proposal/` (AlterLab, MIT, snapshot 2026-09).

1. Read its SKILL.md in full, then only the references needed.
2. Scaffold with `python3 .../alterlab-tubitak-proposal/scripts/scaffold_proposal.py` (offline), outputs under `/workspace`.
3. Forms, page limits, budget caps and deadlines change with each call. Before relying on any of them, check the current call documents and forms on tubitak.gov.tr and ARBiS, and give the date checked.
4. For general proposal craft (aims, impact, work packages, risk), also use the research-grants skill; for BİDEB scholarships, use the turkish-academia skill.
5. Never invent budget items, preliminary results, partner commitments or citations. Use placeholders.
6. Write in TDK spelling, formal and concrete, without em dashes or buzzwords. The evaluation criteria (originality, method, management, impact) should each be answered explicitly.
