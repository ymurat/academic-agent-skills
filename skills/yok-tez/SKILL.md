# YÖK Tez search and originality check

Upstream: `resources/alterlab/skills/turkish-academia/alterlab-yok-tez/` (AlterLab, MIT).

1. Read its SKILL.md in full for search-craft rules (paired TR+EN keywords, stems, filters).
2. **Manual use only.** Automated query scripts and unofficial scrapers/MCP clients for tez.yok.gov.tr were removed from this distribution (2026-11-05). Site terms do not clearly authorize automated querying; there is no official public API. Run searches yourself in a browser at https://tez.yok.gov.tr/UlusalTezMerkezi/ (or give the user the query set).
3. Keep requests light. Full text is only available for İzinli theses and is licensed for online viewing, so don't download theses in bulk.
4. Report originality as an evidence-based judgment: list the closest theses with year, university, and how they differ. Never call a topic "original" without having searched.
5. Also search international sources (a scholarly search tool such as Semantic Scholar or arXiv) when originality matters beyond Turkey.
6. Format APA 7 / BibTeX thesis citations from records the user provides or that you read from the official page this turn.
