## English

### What it does

Searches YÖK Ulusal Tez Merkezi for prior theses, checks topic originality before a proposal, or formats thesis citations.

### When to use

Load this skill when the task matches: search YÖK Ulusal Tez Merkezi for prior theses, check a thesis topic's originality before a proposal, or format thesis citations.

### Example prompts

- Search YÖK Tez for prior theses on LLM-assisted code review in Turkish universities.
- Check originality of this proposed thesis title against Ulusal Tez Merkezi.

- Constraints stated by the user
