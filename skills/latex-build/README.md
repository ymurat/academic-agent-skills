[LaTeX build](./SKILL.md)

## English

### What it does

Creates, compiles, debugs or checks a LaTeX or Overleaf manuscript, thesis or Beamer deck from a venue template; can convert from Word.

### When to use

Load this skill when the task matches: the user wants a LaTeX or Overleaf manuscript, thesis or Beamer deck created from a venue template, compiled, debugged, converted from Word, or checked before submission.

### Example prompts

- Build this IEEE conference paper from the venue template and compile with latexmk.
- Convert this Word thesis chapter to LaTeX under the institute template and list first errors.

### Inputs and outputs

**Inputs**

- Venue template or institute thesis class
- Source content (sections, figures, bib)

**Outputs**

- Structured output defined in SKILL.md
- Limitations and unverifiable items marked plainly
