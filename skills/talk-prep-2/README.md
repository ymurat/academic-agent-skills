# talk-prep-2

[Talk and poster preparation](./SKILL.md)

## English

### What it does

Turns a paper or research into a timed talk script, slides, Q&A preparation or a poster.

### When to use

Load this skill when the task matches: the user needs to present a paper or research (conference talk, seminar, journal club, defense rehearsal, invited talk) or make a poster: timed talk script, slides distilled from it, Q&A preparation, rehearsal, and print-ready speaker notes.

### Example prompts

- Turn this paper into a 12-minute talk script with slide outline and Q&A list.
- Make a conference poster layout from these contribution bullets.

### Inputs and outputs

**Inputs**

- User task and relevant documents
- Constraints stated by the user

**Outputs**

- Structured output defined in SKILL.md
- Limitations and unverifiable items marked plainly
