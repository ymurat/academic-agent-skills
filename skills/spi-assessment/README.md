## English

### What it does

Plans or reviews a software process assessment (ISO/IEC 330xx, Automotive SPICE, CMMI, ISO/IEC 29110), rates process attributes, and does gap analysis or improvement roadmaps.

### When to use

Load this skill when the task matches: planning or reviewing a software process assessment (ISO/IEC 330xx, Automotive SPICE, CMMI, ISO/IEC 29110), rating process attributes, doing a gap analysis or improvement roadmap, or writing an SPI paper for EuroSPI or JSEP.

### Example prompts

- Plan an ISO/IEC 330xx assessment for our student project process. Rate attributes with evidence.
- Do a gap analysis against Automotive SPICE for this supplier process description.
