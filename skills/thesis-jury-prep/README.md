# thesis-jury-prep

[Thesis jury preparation](./SKILL.md)

## English

### What it does

Prepares for a thesis defense or proficiency exam as candidate (question bank, weak points) or as jury member (reading report, questions, decision justification).

### When to use

Load this skill when the task matches: the user prepares for a thesis defense or proficiency exam, either as candidate (mock jury questions, weak points, answer notes) or as a jury member (reading report, question list, decision justification).

### Example prompts

- As candidate prep: build a question bank and weak-point analysis from this thesis PDF.
- As jury member: write a reading report and 10 prioritised questions. Formal Turkish.

### Inputs and outputs

**Inputs**

- Thesis PDF or chapters
- Degree type and user role (candidate, advisor, jury)
- Graduate school regulation (opened live)

**Outputs**

- Structured output defined in SKILL.md
- Limitations and unverifiable items marked plainly
