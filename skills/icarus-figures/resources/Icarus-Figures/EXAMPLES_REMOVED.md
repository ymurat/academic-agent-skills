# examples/ removed in this distribution

The upstream `examples/` directory (large gallery PNGs and demo scripts) was
removed on 2026-11-05 to slim the published skill. It is not required for the
skill to work: follow `references-claude/skills/icarus-figures/SKILL.md`, use `paperfig/`
and `scripts/`, and plot with the user's own data.
