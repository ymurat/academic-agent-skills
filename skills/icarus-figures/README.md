# icarus-figures

[Icarus figures](./SKILL.md)

## English

### What it does

Builds reproducible publication-grade data figures (matplotlib) or TikZ method/framework figures for a paper.

### When to use

Load this skill when the task matches: making reproducible publication-grade data figures (matplotlib) or TikZ method/framework figures for a paper.

### Example prompts

- Make a reproducible matplotlib figure for Figure 3 from results.csv with publication fonts.
- Draw a TikZ method overview figure matching this paper outline.

### Inputs and outputs

**Inputs**

- User task and relevant documents
- Constraints stated by the user

**Outputs**

- Reproducible figure scripts and output images
