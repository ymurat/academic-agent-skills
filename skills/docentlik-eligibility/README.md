# docentlik-eligibility

[Doçentlik pre-screen](./SKILL.md)

## English

### What it does

Pre-screens a publication record against ÜAK doçentlik criteria (all 12 fields, including Mühendislik). Never issues a final eligibility verdict.

### When to use

Load this skill when the task matches: pre-screen a researcher's publication record against ÜAK doçentlik criteria (all 12 fields, including Mühendislik); never gives a final eligibility verdict.

### Example prompts

- Pre-screen this publication list against ÜAK doçentlik criteria for Mühendislik. Do not give a final verdict.
- Score this CV against the current ÜAK table and list gaps with evidence.

### Inputs and outputs

**Inputs**

- User task and relevant documents
- Constraints stated by the user

**Outputs**

- Pre-screen table against ÜAK criteria
- Gaps with evidence; no final verdict
