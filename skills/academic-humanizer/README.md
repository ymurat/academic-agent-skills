## English

### What it does

Edits AI-assisted academic prose toward the author's voice while keeping numbers, results and citations unchanged.

### When to use

Load this skill when the task matches: editing AI-assisted academic prose (papers, theses, rebuttals, grant proposals) for clarity and the author's own voice while keeping scholarly conventions, every number, result, and citation unchanged.

### Example prompts

- Edit this Methods section so it sounds like my own writing. Keep every number and citation unchanged.
- Humanize this AI-drafted rebuttal letter without adding new claims.

### Inputs and outputs

**Inputs**

- Draft academic prose
- Constraint: keep numbers, results and citations unchanged

**Outputs**

- Structured output defined in SKILL.md
- Limitations and unverifiable items marked plainly
