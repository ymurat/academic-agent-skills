# peer-review

[Peer review](./SKILL.md)

## English

### What it does

Produces a structured reviewer report or critique for a manuscript, proposal or preprint.

### When to use

Load this skill when the task matches: the user is reviewing a manuscript, proposal or preprint and needs a structured reviewer report or critique.

### Example prompts

- Write a structured reviewer report for this preprint. Weaknesses first.
- Critique the statistics and threats to validity in this SE experiment paper.

### Inputs and outputs

**Inputs**

- User task and relevant documents
- Constraints stated by the user

**Outputs**

- Structured output defined in SKILL.md
- Limitations and unverifiable items marked plainly
