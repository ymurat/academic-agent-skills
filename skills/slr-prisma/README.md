# slr-prisma

[Systematic Literature Review with PRISMA 2020 (from github.com/keemanxp/slr-prisma by Chuah Kee Man, MIT)](./SKILL.md)

## English

### What it does

Plans, writes, structures or audits a systematic literature review with PRISMA 2020, search strings and inclusion/exclusion criteria.

### When to use

Load this skill when the task matches: the user plans, writes, structures, or audits a systematic literature review (SLR): PRISMA 2020 checklist or flow diagram, search strings for Scopus/WoS/IEEE Xplore, inclusion/exclusion criteria, screening, risk of bias, narrative synthesis. Not for meta-analysis.

### Example prompts

- Draft a PRISMA 2020 flow and search strings for Scopus and IEEE Xplore on LLM code review.
- Audit this SLR protocol for missing inclusion criteria and quality assessment.

- Constraints stated by the user
