# empirical-se-standards

[Empirical SE study design and review (ACM SIGSOFT Empirical Standards)](./SKILL.md)

## English

### What it does

Designs, self-checks or reviews an empirical software engineering study against ACM SIGSOFT Empirical Standards, Runeson and Höst, Wohlin et al., and Kitchenham survey guidance.

### When to use

Load this skill when the task matches: designing, self-checking or reviewing an empirical software engineering study against the ACM SIGSOFT Empirical Standards, Runeson and Höst, Wohlin et al., and Kitchenham survey guidance.

### Example prompts

- Self-check this case study manuscript against the ACM SIGSOFT Empirical Standards.
- Design an empirical SE study on code review tools using Wohlin and Runeson guidance.

- Constraints stated by the user

**Outputs**

- Structured output defined in SKILL.md
- Limitations and unverifiable items marked plainly
