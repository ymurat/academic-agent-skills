# turkish-native

[Natural Turkish](./SKILL.md)

## English

### What it does

Rewrites or reviews Turkish text that reads as translated from English: calques, heavy nominalization, wrong collocations, unnatural word order.

### When to use

Load this skill when the task matches: rewrite or review Turkish text that reads as translated from English: calques, heavy nominalization, wrong collocations, unnatural word order.

### Example prompts

- Rewrite this Methods section so it no longer reads as translated from English.
- Fix calques and heavy nominalization in this öz paragraph.

**Inputs**

- User task and relevant documents
- Constraints stated by the user

**Outputs**

- Structured output defined in SKILL.md
