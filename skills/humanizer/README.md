[Humanizer (from github.com/blader/humanizer, MIT, v3.1.0)](./SKILL.md)

## English

### What it does

Edits prose so it stops sounding AI-written (forced triads, stock AI words, staged openers, inflated claims) without changing the substance.

### When to use

Load this skill when the task matches: editing or reviewing prose so it stops sounding AI-written (dashes everywhere, forced triads, stock AI words, staged openers, one-line closers, inflated claims, sales language) without changing what it says.

### Example prompts

- Remove AI-sounding patterns from this abstract without changing the claims.
- Edit this blog post draft: drop stock AI openers and forced triads.
