# agile-v

[Agile V: requirements and traceability](./SKILL.md)

## English

### What it does

Writes traceable software requirements (REQ IDs, verification criteria), reviews ambiguity, and derives tests from a baseline.

### When to use

Load this skill when the task matches: writing traceable software requirements (REQ IDs, verification criteria), reviewing them for ambiguity, deriving tests from baselined requirements, building a requirements-to-test traceability matrix, or setting up human approval gates.

### Example prompts

- Write REQ IDs and verification criteria for this feature brief.
- Review these requirements for ambiguity and derive acceptance tests from the baseline.
