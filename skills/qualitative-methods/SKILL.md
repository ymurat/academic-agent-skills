# Qualitative methods and surveys

Upstream (AlterLab, MIT, instructions plus one offline script):
- `../../common/alterlab/skills/research-tools/alterlab-qualitative-methods/SKILL.md`: thematic analysis, grounded theory (Strauss and Corbin, Charmaz), coding, Yin-style case studies.
- `../../common/alterlab/skills/research-tools/alterlab-survey-design/SKILL.md`: questionnaires, Likert scales, validation.
- `../../common/alterlab/skills/social-science-workflow/alterlab-qualitative-analysis/SKILL.md`: codebooks, inter-coder reliability with `scripts/icr.py` (standard library; optional `krippendorff`, `statsmodels`).

1. Read only the upstream file(s) the task needs, in full.
2. For software engineering studies, also apply the empirical-se-standards skill (ACM SIGSOFT Empirical Standards, Runeson and Höst for case studies, Kitchenham and Pfleeger for surveys), which the upstream doesn't cover.
3. For studies with human participants in Turkey, check ethics and data protection with ethics-committee and turkish-academia (Etik Kurul, KVKK).
4. Never invent codes, quotes or reliability figures. Transcripts and participant data stay on local storage.
5. Write plainly and precisely; avoid em dashes and buzzwords.
