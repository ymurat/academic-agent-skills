# experimental-design

[Experimental Design](./SKILL.md)

## English

### What it does

Chooses a study design before data collection: randomization, blocking, factorial or fractional-factorial DOE, crossover, repeated measures or cluster designs.

### When to use

Load this skill when the task matches: planning a study before data collection: choosing a design, randomization, blocking or stratification, factorial or fractional-factorial DOE, crossover or repeated measures, cluster randomization, Latin squares, run order, or sequential designs.

### Example prompts

- Choose a design for a 2x3 factorial SE experiment with two sites. Propose randomization.
- Plan blocking and sample allocation before we collect developer task data.
