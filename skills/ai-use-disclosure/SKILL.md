# AI-use disclosure

Full draft with publisher table, decision flow, EN/TR templates and logging habit: `resources/ai-use-disclosure/SKILL.md`. Policy pages were first checked on 2026-10-31.

1. Read that file in full.
2. Before stating any publisher, funder or YÖK rule to the user, open that body's official policy page (URLs are in the file) and confirm the rule this turn. Policies change often. Give the date checked.
3. Treat every cell marked "confirm" as unverified until you read it on the official page. Known gaps at the time of writing: Wiley placement, copy-edit and peer review rules; Sage (only search excerpts read); IEEE and ACM details beyond authorship; Springer Nature placement; YÖK rules on copy-editing, peer review and images; several cells written from memory (listed in the file or in its notes). If a rule can't be verified, say so plainly.
4. DergiPark and TR Dizin have no shared policy; check the specific journal's author guidelines.
5. Ask what was actually done with AI (tool, version, purpose, which sections, how output was checked) rather than guessing. Never overstate or understate the use.
6. Draft the statement in the target language using the templates; Turkish follows TDK spelling and natural academic style (see turkish-native). Writing rules: no em dashes, no buzzwords, plain and specific.
7. Recommend keeping a simple log (date, tool and version, prompt purpose, section, how checked) for future disclosures.
