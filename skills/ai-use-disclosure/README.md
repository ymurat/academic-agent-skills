# ai-use-disclosure

[AI-use disclosure](./SKILL.md)

## English

### What it does

Writes, places or checks an AI-use disclosure for a paper, thesis, grant proposal or peer review report against a publisher, funder or YÖK rule.

### When to use

Load this skill when the task matches: an academic needs to write, check or place an AI-use disclosure statement for a paper, thesis, grant proposal or peer review report, or asks whether a given AI use must be disclosed for a specific publisher, funder or YÖK.

### Example prompts

- Draft an AI-use disclosure for this IEEE paper. I used Claude for grammar only on the Related Work section.
- Does this Springer journal require disclosure for citation formatting with an LLM? Check the current policy page.

### Inputs and outputs

**Inputs**

- User task and relevant documents
- Constraints stated by the user

**Outputs**

- Disclosure statement in target language
- Policy pages checked with date
