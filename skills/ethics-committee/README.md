# ethics-committee

[Ethics committee review](./SKILL.md)

## English

### What it does

Reviews a research protocol the way an ethics committee (IRB, REC, Etik Kurul) would, before submission or when answering committee feedback.

### When to use

Load this skill when the task matches: review a research protocol the way an ethics committee (IRB, REC, Etik Kurul) would, before an ethics submission or when answering committee feedback.

### Example prompts

- Review this interview protocol the way an Etik Kurul would, before we submit.
- Draft answers to these ethics committee revision requests.
